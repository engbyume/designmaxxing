# designmaxxing

A first-pass UI/UX design skill for websites, apps, games, dashboards, components, and design systems.

## Use

Load SKILL.md before matching specialist design skills. Read only the references that fit the task. For work involving both UI/UX and application security, load securitymaxxing in the same first pass.

## Package

- SKILL.md contains the skill trigger and design workflow.
- references/ contains focused design guidance.
- THIRD_PARTY_NOTICES.md records the MIT notice for the Apple Design distillation.
